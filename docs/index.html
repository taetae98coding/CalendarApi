CalendarApi

공휴일과 음력 정보를 정적 JSON 으로 제공하는 API 입니다. GitHub Actions 가 주기적으로 갱신합니다.

마지막 갱신 : 2026-09-24T04:59:16.894443Z

경로

제공 범위는 세 API 모두 1998 ~ 2050 로 같습니다. {country} 는 kr, us 이고 {month} 는 01 ~ 12 입니다.

설명연도월
공휴일holiday/{country}/{year}.jsonholiday/{country}/{year}/{month}.json
음력lunar/{country}/{year}.jsonlunar/{country}/{year}/{month}.json
통합calendar/{country}/{year}.jsoncalendar/{country}/{year}/{month}.json

필요한 것만 받으려면 holiday · lunar 를, 한 번에 받으려면 calendar 를 쓰면 됩니다. 범위 안이지만 원천에 자료가 없는 구간은 빈 목록([])으로 내려갑니다.
